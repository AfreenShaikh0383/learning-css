CSS Grid Concepts Used

  • display: grid
  • grid-template-columns
  • grid-template-rows
  • grid-template-areas
  • grid-area
  • gap
  • repeat()
  • fr unit
  • Media queries

Basic Structure

.website {
    display: grid;

    grid-template-columns: 200px 1fr;

    grid-template-rows:
        80px
        1fr
        70px;

    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}
