What is a Media Query?

A media query allows CSS rules to be applied only when specific conditions are true.

Basic Syntax

@media (max-width: 600px) {

    body {
        background-color: lightblue;
    }

}

Different Breakpoints

A webpage can have multiple media queries.

/* Tablet */
@media (max-width: 800px) {
    ...
}

/* Mobile */
@media (max-width: 600px) {
    ...
}

Media Query Features

  • max-width

  • orientation
  • screen size based layouts
