CSS Introduction

CSS stands for Cascading Style Sheets.

What is CSS?

CSS is used to style and design HTML elements.

HTML creates the structure, while CSS controls the appearance and layout.

1. Inline CSS

This paragraph uses inline CSS.

CSS is written directly inside the style attribute. 

<p style="color: blue;">
    This is inline CSS.
</p>

2. Internal CSS

This paragraph uses internal CSS.

Internal CSS is written inside a <style> element in the <head>. 

<style>

    .example {
        color: blue;
    }

</style>

3. External CSS

This paragraph is styled using an external CSS file.

This is the method we will mainly use in this repository.

<link rel="stylesheet" href="01-css-introduction.css">

Basic CSS Syntax

selector {
    property: value;
}

Example:

p {
    color: blue;
    font-size: 20px;
}

What does "Cascading" mean?

When multiple CSS rules apply to the same element, the browser determines which rule should take priority.

This depends on factors such as importance, specificity and source order.

Why use CSS?

  • Change colors
  • Change fonts
  • Control spacing
  • Create layouts
  • Make websites responsive
  • Add animations and transitions
  • Separate design from HTML structure
