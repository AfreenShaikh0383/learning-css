6. Grid Terminology

  • Grid Container: Parent element with display: grid.
  • Grid Item: Direct child of the grid container.
  • Grid Row: Horizontal track in the grid.
  • Grid Column: Vertical track in the grid.
  • Gap: Space between grid items.

7. Basic Grid Syntax

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 20px;
}
