7. Important Flexbox Terms

  • Flex Container: Parent element with display: flex.
  • Flex Items: Direct children of the flex container.
  • Main Axis: Primary direction of the flex layout.
  • Cross Axis: Direction perpendicular to the main axis.
  • gap: Space between flex items.

8. Basic Flexbox Syntax

.container {
    display: flex;
    gap: 20px;
}
