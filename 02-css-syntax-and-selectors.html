CSS Syntax & Selectors

Selectors tell CSS which HTML elements should be styled.

CSS Syntax

selector {
    property: value;
}

Example:

p {
    color: blue;
}

1. Element Selector

This paragraph is selected using the element selector.

Example:

p {
    color: blue;
}

2. Class Selector

This paragraph has a class.

Multiple elements can use the same class.

.highlight {
    background-color: yellow;
}

3. ID Selector

This paragraph has a unique ID.

#special-text {
    color: red;
}

4. Universal Selector

The universal selector targets all elements.

* {
    margin: 0;
}

5. Group Selector

Heading Example

Paragraph Example

h1, h2, p {
    color: green;
}

6. Descendant Selector

This paragraph is inside the container.

This paragraph is nested inside another div.

.container p {
    color: purple;
}

7. Child Selector

Direct child paragraph

Nested paragraph

.parent > p {
    color: orange;
}

8. Attribute Selector

input[type="text"] {
    border: 2px solid blue;
}

9. Multiple Classes

This element has two classes.

.text.large {
    font-size: 24px;
}
