What is Responsive Design?

Responsive design means creating webpages that adjust their layout according to the size of the screen.

The same website can work on desktops, tablets and mobile phones.

Why Responsive Design?

  • Desktop screens have more available space.
  • Mobile screens have less available space.
  • Text should remain readable.
  • Images should fit the screen.
  • Navigation may need to change.
  • Columns may need to become rows.

Important Viewport Setting

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>

This tells the browser to use the device's actual screen width when displaying the webpage.
