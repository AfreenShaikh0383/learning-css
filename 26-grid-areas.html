26 - Grid Areas

Grid areas allow us to give names to different sections of a grid layout.

1. Basic Grid Areas

Header
Sidebar
Main Content
Footer

2. Grid Area Syntax

.container {
    display: grid;

    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

.header {
    grid-area: header;
}

.sidebar {
    grid-area: sidebar;
}

.main {
    grid-area: main;
}

.footer {
    grid-area: footer;
}

5. Important Rules

  • grid-template-areas defines named areas.
  • grid-area assigns an element to a named area.
  • Names are written inside quotes.
  • Each row is written as a separate string.
