12. Quick Reference

  • justify-items → horizontal alignment of items inside their grid areas
  • align-items → vertical alignment of items inside their grid areas
  • place-items → shorthand for both
  • justify-content → horizontal alignment of the entire grid
  • align-content → vertical alignment of the entire grid
  • place-content → shorthand for both

13. Example Syntax

.container {
    display: grid;

    justify-items: center;
    align-items: center;

    /* Shorthand */
    place-items: center;
}
