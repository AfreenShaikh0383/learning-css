CSS Width and Height

The width and height properties control the size of an element.

1. Width

This box has a width of 300px.

2. Height

This box has a height of 150px.

3. Width and Height Together

Width: 300px
Height: 150px

4. Percentage Width

Width: 50% of the parent

5. Max Width

This element cannot become wider than 500px.

6. Min Width

This element has a minimum width.

7. Max Height

This content demonstrates maximum height.

More content can make the element reach its maximum height.

8. Min Height

This element has a minimum height.

9. Auto

The browser automatically calculates the width and height.
