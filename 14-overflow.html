CSS Overflow

Overflow controls what happens when content is larger than the available space inside an element.

1. Overflow: Visible

This content is larger than the box. With overflow: visible, the extra content can appear outside the element.

2. Overflow: Hidden

This content is larger than the box. The extra content is hidden when it goes outside the box.

3. Overflow: Scroll

This box has a fixed size. More content creates scrollbars so the user can scroll through the hidden content. This is useful when you want a fixed-size scrolling area.

4. Overflow: Auto

This box automatically provides scrolling when the content becomes larger than the available space. Add more content to see the scrollbar.
