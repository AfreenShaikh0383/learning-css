9. Important Syntax

.container {
    display: grid;

    grid-template-columns: 1fr 1fr 1fr;

    grid-template-rows: 100px 200px;

    gap: 20px;
}

10. Quick Reference

  • grid-template-columns → controls column sizes
  • grid-template-rows → controls row sizes
  • 1fr → one fraction of available space
  • repeat(3, 1fr) → three equal columns
  • 100px 200px → fixed-size tracks
