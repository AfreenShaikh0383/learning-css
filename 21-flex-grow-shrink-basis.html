21 - Flex Grow, Shrink & Basis

Flexbox provides properties that control how flex items grow, shrink, and determine their initial size.

8. Syntax

.item {
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: 200px;
}

9. Shorthand Syntax

.item {
    flex: 1 1 200px;
}

10. Important Properties

  • flex-grow: Controls growth when extra space exists.
  • flex-shrink: Controls shrinking when space is insufficient.
  • flex-basis: Sets the initial size of the item.
  • flex: Shorthand for grow, shrink and basis.
